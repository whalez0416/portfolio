# 최희준 — 포트폴리오

의료 마케팅 도메인에서 AEO(답변엔진 최적화) 측정 · 생산 · 감시 도구를 직접 개발해 운영한 기록.

**https://whalez0416.github.io/portfolio/**

## 구성

정적 HTML 한 장입니다. 빌드 과정도, 의존성도, CI도 없습니다.

```
index.html    전부 — 마크업 · CSS · 3D 사막 게임(WebGL2) · 로그 분석기
```

맨 위는 **게임입니다.** 이력서를 걸어서 지나갑니다.

**길은 서사, 유적은 프로그램.** 걸으면 제 이력이 흐르고, 모래에 묻힌 유적에 들어가면
그때 만든 것이 나옵니다. 하나도 안 들어가고 산까지 걸어도 이력은 완결됩니다.
서사 원문은 [`docs/narrative.md`](docs/narrative.md), 유적 안의 문장은
[`docs/programs.md`](docs/programs.md)에 있고 — **화면에 뜨는 문장은 전부 그 두 문서에 있습니다.**

**등 뒤에서 보는 시점 하나로 사막을 걸어 지평선의 산까지 갑니다.** 중간에 시점이 바뀌지 않습니다.
조작은 <kbd>↑</kbd> 걷기와 <kbd>←</kbd><kbd>→</kbd> 방향 둘뿐이고, **정해진 길이 없습니다** —
트인 사막이라야 어디로 갈지가 실제로 내 선택이 되고, 방향은 지평선의 산이 줍니다.

출발할 때는 노출을 팔던 무리와 같은 길을 걷습니다. 어느 지점에서 무리가 한꺼번에 꺾어 가고,
한 명이 멈춰 돌아봅니다. 저는 산 쪽으로 계속 걷습니다.

유적은 **만든 순서(커밋 날짜)** 대로 산 쪽에 놓여 있습니다. 정리하기 좋은 순서가 아니라 실제 순서입니다.

| # | 유적 | |
|---|---|---|
| 1 | aeo_sync | "AI에 인용되는 글"이 뭔지 아무도 정의해 주지 않았습니다 |
| 2 | MediSTT | 모델이 좋아지길 기다리는 대신 도메인 사전으로 막았습니다 |
| 3 | MetaPorter | 메타는 병원이 운영하기에 까다로운 매체입니다 |
| 4 | SERP Sentinel | 순위 변동은 산출물이 아니라 수단입니다 |
| 5 | KPIY | 정확해야 하는 곳에는 검색이 아니라 실행을 붙였습니다 |
| **6** | **aeo-log-analyzer** | **랜턴 — 여기서 나오는 순간 안 보이던 것이 전부 켜집니다** |
| 7 | NetTier | 추정은 틀리지만 실측은 안 틀립니다 |
| — | **빈 문틀** | Price Lock. 만들어 놓고 지웠습니다. **절대 안 열립니다** |
| 8 | Hospify | 못 지킬 약속은, 자리를 비워둡니다 |

**계측기가 여섯 번째인 것이 이 게임의 전부입니다.** 1~5번 유적을 지나는 내내 크롤러는
보이지 않습니다. 실제로 7개월을 그렇게 만들었고, 만들고 나서야 증명할 방법이 없다는 걸
알았습니다. 여섯 번째 유적에서 **나오는 순간** 사막 전체에 앰버 티끌이 떠오릅니다 —
그동안에도 계속 지나다니고 있었는데, 이제야 보이는 것들.

기능 설명은 게임 안에 복제하지 않습니다. 문 안의 본문은 아래 `대표 프로젝트` 마크업을 그대로 꺼내 씁니다 —
**본문은 한 벌뿐**이라, 기록을 고치면 게임도 따라 바뀝니다.
걷기 싫은 사람은 그냥 스크롤하면 같은 내용이 글로 있습니다.

지형·인물·유적·티끌은 전부 코드로 만듭니다. 렌더러는 **WebGL2**인데 의존성은 여전히 0입니다 —
WebGL2는 라이브러리가 아니라 브라우저 기본 기능이고, 텍스처도 모델도 외부 파일이 아닙니다.
인물은 사다리꼴 로브 + 각진 크리스 + 열린 옷단으로 조각했고, 법선을 넘기지 않고 프래그먼트에서
미분으로 구해 지형도 로브도 스카프도 **같은 셰이더**로 플랫셰이딩됩니다.

**WebGL2가 없는 브라우저에서도 페이지는 깨지지 않습니다** — 그림만 빠지고 안내는 그대로이며,
같은 내용이 아래에 전부 글로 있습니다. 소리는 오실레이터 셋뿐이고 기본은 꺼져 있습니다.

`?selftest`를 주소에 붙이면 콘솔에서 검증됩니다.
**계측기가 여섯 번째인지**, 유적이 만든 순서대로 놓였는지, 유적 이름이 실제 기록과 맞는지,
대본이 산 쪽으로만 흐르는지, 빈 문틀 자리와 산의 거리까지 여기서 잡힙니다.

```
https://whalez0416.github.io/portfolio/?selftest
```

검사는 넷이고 **서로 다른 종류의 실패**를 잡습니다. 앞의 둘은 의존성 없이 node만 있으면 됩니다.

```bash
node test/walk.js      # 끝까지 갈 수 있는가 (브라우저 없이 실제로 걸어본다)
node test/a11y.js      # 진짜 브라우저에서 접근성이 성립하는가
node test/shoot.js     # 실제로 어떻게 보이는가 (프레임 촬영)
node test/journey3d.js # 열 장면이 제대로 조립됐는가
```

폰트는 Google Fonts(Space Grotesk · Space Mono)와 jsDelivr(Pretendard)에서 받아오고,
차단된 환경에서는 시스템 폰트로 폴백합니다.
