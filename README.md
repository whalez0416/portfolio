# 최희준 — 포트폴리오

의료 마케팅 도메인에서 AEO(답변엔진 최적화) 측정 · 생산 · 감시 도구를 직접 개발해 운영한 기록.

**https://whalez0416.github.io/portfolio/**

## 구성

정적 HTML 한 장입니다. 빌드 과정도, 의존성도, CI도 없습니다.

```
index.html    전부 — 마크업 · CSS · 횡스크롤 게임 · 로그 분석기
```

맨 위는 **게임입니다.** 이력서를 걸어서 지나갑니다.

**길은 서사, 문은 프로그램.** 걸으면 제 이력이 흐르고, 길가의 문에 들어가면 그때 만든 것이 나옵니다.
문은 하나도 안 열고 끝까지 걸어도 이력은 완결됩니다. 서사 원문은 [`docs/narrative.md`](docs/narrative.md),
문 안의 문장은 [`docs/programs.md`](docs/programs.md)에 있고 — **화면에 뜨는 문장은 전부 그 두 문서에 있습니다.**

**1~5장 · 위에서 내려다보는 시점** (2014 → 2025). 노출을 팔던 무리와 같은 포장도로를 같이 걷습니다.
정수리만 보이는 각도라 무리 속에서 다들 똑같이 생겼고, 앰버 점이 찍힌 흰 정수리 하나가 나입니다.
갈림길에서 아래로 내려서면 **카메라가 옆으로 눕습니다.** 무리는 그대로 직진해 길 끝에서 사라집니다.
시점 전환은 연출이 아니라 필요입니다 — 횡스크롤은 길이 한 줄이라 "다른 길로 갔다"를 그릴 수 없습니다.

**6~10장 · 횡스크롤** (2025-12 → 2026-08). 바닥이 눈금 있는 **계측 그리드**로 바뀝니다.
추정 대신 재는 쪽을 매번 골랐으니, 달리는 바닥에 눈금이 있는 건 배경이 아니라 인물 설정입니다.

문은 **만든 순서(커밋 날짜)** 대로 놓여 있습니다. 정리하기 좋은 순서가 아니라 실제 순서입니다.

| # | 문 | 열리는 것 |
|---|---|---|
| 1 | aeo_sync | <kbd>↓</kbd> 발행 — 페이지를 심습니다. 읽히는지는 모릅니다 |
| 2 | MediSTT | 자막 — 발행한 페이지가 더 자주 읽힙니다 |
| 3 | MetaPorter | 인용 계기판 — 켜지는데 눈금이 <b>?</b> 입니다 |
| 4 | SERP Sentinel | 레이더 — 경쟁사 페이지와 점유율이 드러납니다 |
| 5 | KPIY | KPI — 관측값이 그래프로 쌓입니다 |
| 6 | aeo-log-analyzer | **랜턴 — 안 보이던 것이 전부 켜지고, `?`가 숫자가 됩니다** |
| 7 | NetTier | 국경 개방 — 앞을 막던 벽이 열립니다 |
| 8 | Hospify | 도착 — 만들어 놓고 지운 자리 |

**계측기가 여섯 번째인 것이 이 게임의 전부입니다.** 1~5번 문을 지나는 내내 크롤러는 보이지 않고
인용 계기판은 `?`에 멈춰 있습니다. 실제로 7개월을 그렇게 만들었고, 만들고 나서야 증명할 방법이
없다는 걸 알았습니다. 여섯 번째 문에서 화면 전체가 한 번에 드러납니다.

기능 설명은 게임 안에 복제하지 않습니다. 문 안의 본문은 아래 `대표 프로젝트` 마크업을 그대로 꺼내 씁니다 —
**본문은 한 벌뿐**이라, 기록을 고치면 게임도 따라 바뀝니다.
걷기 싫은 사람은 그냥 스크롤하면 같은 내용이 글로 있습니다.

캐릭터·배경·크롤러는 전부 코드로 그린 픽셀 스프라이트입니다. 외부 에셋도 스프라이트시트 요청도 없습니다.
소리는 오실레이터 몇 개로 만들었고 기본은 꺼져 있습니다. `prefers-reduced-motion`을 켜 두면 흔들림과 먼지가 빠집니다.

`?selftest`를 주소에 붙이면 콘솔에서 검증됩니다.
장면 열 개의 순서, **계측기가 여섯 번째인지**, 인용 계기판이 랜턴 전에 `?`이고 후에 숫자인지,
도구 이름이 실제 기록과 맞는지, 세 레인의 난이도 구배와 재크롤 대기까지 여기서 잡힙니다.

```
https://whalez0416.github.io/portfolio/?selftest
```

브라우저를 열지 않고 **실제로 끝까지 걸어보는** 테스트도 있습니다.
`index.html`의 스크립트를 그대로 꺼내 최소 DOM 스텁 위에서 돌리고, 1장부터 엔딩까지 조작합니다.
의존성은 없고 node만 있으면 됩니다.

```bash
node test/walk.js
```

폰트는 Google Fonts(Space Grotesk · Space Mono)와 jsDelivr(Pretendard)에서 받아오고,
차단된 환경에서는 시스템 폰트로 폴백합니다.

## 로컬에서 보기

```bash
python -m http.server 8000
# http://localhost:8000
```

파일을 브라우저로 바로 열어도 됩니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 자동 반영합니다.
(Settings → Pages → Source: `main` / `/root`)
