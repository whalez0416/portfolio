# 최희준 — 포트폴리오

의료 마케팅 도메인에서 AEO(답변엔진 최적화) 측정 · 생산 · 감시 도구를 직접 개발해 운영한 기록.

**https://whalez0416.github.io/portfolio/**

## 구성

정적 HTML 한 장입니다. 빌드 과정도, 의존성도, CI도 없습니다.

```
index.html    전부 — 마크업 · CSS · 횡스크롤 게임 · 로그 분석기
```

맨 위는 **게임입니다.** 시점이 한 번 바뀝니다.

**프롤로그 — 위에서 내려다보는 시점.** 검색 순위를 팔던 사람들과 같은 포장도로를 같이 걷습니다.
정수리만 보이는 각도라 무리 속에서 다들 똑같이 생겼고, 앰버 점이 찍힌 흰 정수리 하나가 나입니다.
길은 갈수록 파손되고, 갈림길에서 아래로 내려서면 **카메라가 옆으로 눕으면서** 횡스크롤이 시작됩니다.
무리는 그대로 직진해 길 끝에서 사라집니다.

시점 전환은 연출이 아니라 필요입니다 — 횡스크롤은 길이 한 줄이라 "다른 길로 갔다"를 그릴 수 없습니다.

**본편 — 횡스크롤 플랫포머.** 걷고, 점프하고, 도구를 줍습니다.
핵심은 **조작법이 곧 주장이라는 것**입니다. 도구를 하나 주울 때마다 동사가 하나씩 열립니다.

| 막 | 도구 | 열리는 동사 |
|---|---|---|
| 0 · 출발 | — | 이동뿐. 다 같은 길을 갑니다 |
| 1 · 위협 | — | 없음. 혼자가 됐고, 방문자가 떠나는 걸 보기만 합니다 |
| 2 · 측정 | aeo-log-analyzer · MetaPorter | 랜턴 — 안 보이던 AI 크롤러가 보이고, 점프로 계측합니다 |
| 3 · 생산 | aeo_sync · MediSTT | <kbd>↓</kbd> 발행 — 심은 페이지로 크롤러가 찾아옵니다 |
| 4 · 감시 | SERP Sentinel · KPIY | 레이더 — 경쟁사 페이지와 점유율이 드러납니다 |
| 5 · 확장 | NetTier · Hospify | 국경 개방 — 1막에서 떠났던 사람들이 반대로 들어옵니다 |

1막에서 아무것도 못 하게 만든 것이 의도입니다. 그게 출발점이었습니다.

게임은 정보를 텍스트 모달로 떠넘기지 않습니다. 도구를 주우면 판단 한 줄만 스치고
지나가고, 8개 기록 전문은 엔딩 화면에서 링크로 열거나 도구 옆에서 <kbd>Enter</kbd>로 엽니다.
그 내용은 아래 `대표 프로젝트` 섹션의 마크업을 그대로 꺼내 씁니다 —
**본문은 한 벌뿐**이라, 기록을 고치면 게임도 따라 바뀝니다.
걷기 싫은 사람은 그냥 스크롤하면 같은 내용이 글로 있습니다.

캐릭터·배경·크롤러는 전부 코드로 그린 픽셀 스프라이트입니다.
외부 에셋도, 스프라이트시트 요청도 없습니다.

`?selftest`를 주소에 붙이면 콘솔에서 검증됩니다.
도구 이름이 실제 기록과 어긋나거나, 세 레인의 난이도 구배(지상 / 점프 / 발판)가
깨지거나, 재크롤 대기가 풀리면 여기서 잡힙니다.

```
https://whalez0416.github.io/portfolio/?selftest
```

폰트는 Google Fonts(Space Grotesk · Space Mono)와 jsDelivr(Pretendard)에서 받아오고,
차단된 환경에서는 시스템 폰트로 폴백합니다.

## 로컬에서 보기

```bash
python -m http.server 8000
# http://localhost:8000
```

파일을 브라우저로 바로 열어도 됩니다.

## 배포

`main` 브랜치에 푸시하면 GitHub Pages가 자동 반영합니다.
(Settings → Pages → Source: `main` / `/root`)
